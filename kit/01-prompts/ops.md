# Ops Prompts

---

### SOP From a Loom/Transcript
**Use when:** Documenting a process someone just explained.
```
Turn this walkthrough into a clean SOP.

INPUTS:
- Transcript / notes of the process: [paste]

OUTPUT: Purpose · When to run it · Numbered steps (action + expected result) · Tools needed · Common mistakes · Owner.
```

---

### Meeting Notes → Action Items
**Use when:** After any meeting.
```
Summarize this meeting and extract owned action items.

INPUTS:
- Transcript/notes: [paste]

OUTPUT: 3-bullet summary · Decisions made · Action items as [Owner] — [Action] — [Due] · Open questions.
```

---

### Hiring Scorecard + JD
**Use when:** Opening a role.
```
You are a hiring manager. Write a scorecard and job description.

INPUTS:
- Role + what success looks like in 90 days: [paste]

OUTPUT: Mission (1 line) · 4-5 outcomes (measurable) · Must-have competencies · A JD written to attract A-players (not a checklist dump).
```

---

### Weekly Priorities Planner
**Use when:** Monday planning.
```
Help me plan my week for leverage, not just activity.

INPUTS:
- My goals this quarter: [paste] · Everything on my plate this week: [paste]

OUTPUT: The 3 things that actually move the goal · What to delegate/drop · A time-blocked shape for the week.
```

---

### Process Bottleneck Diagnosis
**Use when:** Something feels slow.
```
Diagnose the bottleneck in this process.

INPUTS:
- How the process works today, end to end: [paste] · Where it feels slow: [paste]

OUTPUT: Most likely constraint + why · 2 quick fixes (this week) · 1 structural fix · What to measure to confirm.
```

---

### Customer Onboarding Checklist
**Use when:** Standardizing onboarding.
```
Build an onboarding checklist that gets customers to first value fast.

INPUTS:
- What I sell + what "first value" means for them: [paste]

OUTPUT: Pre-kickoff · Kickoff · First-value milestone · 30-day check-in. Each with the owner and the success signal.
```
