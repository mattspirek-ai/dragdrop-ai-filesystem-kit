# SEO Prompts

---

### Keyword Cluster Builder
**Use when:** Planning content around a topic.
```
You are an SEO strategist. Build a topic cluster.

INPUTS:
- Seed topic: [paste] · Audience + their stage of awareness: [paste]

OUTPUT: 1 pillar page topic · 8-12 supporting article topics grouped by search intent (informational/commercial/transactional) · internal-linking suggestion.
```

---

### Search-Intent SEO Brief
**Use when:** Briefing a writer (or yourself).
```
Write an SEO content brief for one target keyword.

INPUTS:
- Target keyword: [paste] · Audience: [paste] · Our angle/POV: [paste]

OUTPUT: Search intent · Recommended title (3) · H2/H3 outline · Questions to answer (from "people also ask" style) · Word-count range · Internal links to include · The unique angle that beats current top results.
```

---

### Meta Title + Description
**Use when:** Optimizing a page's SERP snippet.
```
Write SERP-optimized metadata.

INPUTS:
- Page topic + target keyword: [paste]

OUTPUT: 5 title tags (≤60 chars, keyword near front) · 3 meta descriptions (≤155 chars, with a CTA). Flag any that exceed limits.
```

---

### Content Gap Analysis
**Use when:** Competitors outrank you.
```
Analyze the gap between my page and the top results.

INPUTS:
- My page (paste content or URL summary): [paste] · What the top-ranking pages cover (paste notes): [paste]

OUTPUT: Topics they cover that I miss · Where I'm thin · 5 concrete additions ranked by impact.
```

---

### FAQ Schema Generator
**Use when:** You want rich results.
```
Generate FAQ content + JSON-LD schema for a page.

INPUTS:
- Page topic: [paste]

OUTPUT: 6 genuinely-asked questions with concise answers, then valid FAQPage JSON-LD ready to paste.
```

---

### Internal Linking Plan
**Use when:** Your site has orphan content.
```
Propose an internal linking plan.

INPUTS:
- List of my key pages + their topics: [paste]

OUTPUT: A link map (which page should link to which + suggested anchor text) prioritizing money pages.
```
