# Client Onboarding & Delivery Guide

How to deliver the kit so clients reach first value fast and stick around.

## Choose a delivery vehicle
| Vehicle | Best for | How |
|---------|----------|-----|
| **Notion workspace** | Self-serve product + Operating System clients | Duplicate a master workspace; share as a template link |
| **Claude Project** | Agents + skills, non-technical clients | Create a Project, paste agents into instructions, attach skills as files |
| **Claude Code repo** | Technical clients / teams | Give them this repo structure; skills auto-load from `kit/02-skills` |
| **Downloadable pack** | Low-ticket product | Zip the `kit/` folder + a quick-start PDF |

## First-value milestone (aim for day 1)
Get the client to run **one** workflow end-to-end and see a real output. Recommended:
[Inbound → Booked Call] or one LinkedIn post in their voice. First value > full setup.

## Onboarding checklist
**Pre-kickoff**
- [ ] Collect: ICP, offer, proof points, 3-5 brand-voice samples, tools they use.
- [ ] Confirm which System(s) they bought.

**Kickoff (live, 60 min)**
- [ ] Walk the 5 layers and how they connect.
- [ ] Codify their voice (Brand Voice Guide prompt) together.
- [ ] Run one workflow live → first value.

**First value (day 1-3)**
- [ ] Client independently produces one real output.
- [ ] Tailor 2-3 agents/prompts to their niche.

**30-day check-in**
- [ ] Review the metrics each workflow tracks.
- [ ] Identify the upsell (System install → managed retainer).

## Support model
- Shared doc for questions; 48-hr response.
- Monthly office hours for retainer clients.
- Version updates pushed to the shared workspace.

## Common pitfalls
- **Skipping voice setup** → generic output, client churns. Never skip it.
- **Selling the parts, not the outcome** → overwhelm. Lead with one workflow.
- **No first-value moment in week 1** → momentum dies. Engineer it on day 1.
