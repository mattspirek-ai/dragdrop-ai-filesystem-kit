# spiAI Business Development Kit — Pricing & Packaging

Three ways to monetize the kit. Most operators run all three: a low-ticket product for
volume, a service for margin, and systems for the high end.

## 1. Self-Serve Kit (product)
The full kit, delivered as a Notion workspace or downloadable pack.
| Tier | Includes | Price |
|------|----------|-------|
| Starter | Prompts + Skills (Layers 1-2) | $97–197 |
| Pro | + Agents + Workflows (Layers 1-4) | $297–497 |
| Complete | + all 3 Systems + future updates | $497–997 |

## 2. Done-With-You Install (service)
You set the kit up inside the client's business and train their team.
| Package | Scope | Price |
|---------|-------|-------|
| Single System install | One System (e.g. LinkedIn or Sales) | $2,500–5,000 |
| Full kit install | All layers wired into their Claude + tools | $5,000–12,000 |
| Custom build | Bespoke agents/workflows for their niche | $8,000–25,000 |

## 3. Managed Service (retainer)
You run the cadence for them month over month.
| Retainer | What you run | Price/mo |
|----------|--------------|----------|
| Content engine | LinkedIn Content System | $1,500–3,000 |
| Sales engine | Full Sales System cadence | $2,000–5,000 |
| Fractional ops | Claude + Notion Operating System | $1,500–4,000 |

## Pricing principles
- **Anchor on outcomes, not assets.** "A booked-call pipeline," not "44 prompts."
- **Make the middle tier the obvious choice.**
- **Land with a System, expand into a retainer.**

## Suggested first offer
Pick ONE System, sell the Done-With-You install at $3,500, and offer a managed retainer
as the natural follow-on. One clear offer outsells a menu.
