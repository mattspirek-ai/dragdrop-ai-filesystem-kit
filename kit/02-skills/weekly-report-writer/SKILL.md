# Weekly Report Writer

## When to use
The user has raw updates/metrics and needs a clear report for a client or leadership.

## Inputs you need
- Raw updates / what got done this period
- Key metrics (and prior-period values if available)
- Goals this work ladders up to

## Steps
1. Lead with outcomes and movement on the goal, not activity logs.
2. Show metrics with direction (▲/▼) and context, not just numbers.
3. Separate "done", "in progress", "blocked/needs decision".
4. Make asks explicit — what you need from the reader.
5. Keep it scannable in under 60 seconds.

## Output format
```
TL;DR (2 lines)
Progress vs goal: ...
Metrics: metric — value (▲/▼ vs last week) — note
Done this week: - ...
In progress: - ...
Needs a decision from you: - ...
Next week's focus: - ...
```

## Quality bar
- A busy reader gets the state of things from the TL;DR alone.
- Every "blocked" item names who can unblock it.
- No vanity metrics without a "so what".

## Example
**Input:** bullet-point updates + 4 KPIs.
**Output:** A 60-second report opening with "On track for the Q3 pipeline goal; one decision needed on ad budget."
