# Automation Layer — Workflows

A **workflow** chains prompts, skills, and agents into a repeatable, end-to-end play that
produces a business outcome. Each step names the asset it uses, so the whole kit works
together instead of as loose parts.

## Included (v1)
| Workflow | Outcome | File |
|----------|---------|------|
| Inbound Lead → Booked Call | Convert a new inbound into a scheduled call | [inbound-to-booked-call.md](inbound-to-booked-call.md) |
| Topic → Published + Distributed | One topic to a ranked article + a week of posts | [topic-to-published-content.md](topic-to-published-content.md) |
| Cold List → Replies | Run a personalized outbound campaign that books meetings | [cold-list-to-replies.md](cold-list-to-replies.md) |
| Discovery Call → Signed Proposal | Move from first call to a signed deal | [discovery-to-signed-proposal.md](discovery-to-signed-proposal.md) |

Target catalog: 25+ (one per end-to-end outcome) — see [../ROADMAP.md](../ROADMAP.md).
New workflows use [_TEMPLATE.md](_TEMPLATE.md).
