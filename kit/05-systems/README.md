# Growth Engine Layer — Systems

A **System** is a packaged, sellable, end-to-end offering that wires together prompts,
skills, agents, and workflows to run a whole business function on autopilot. Systems are
the highest-margin tier — you sell the *outcome*, not the parts.

> Each system can transform a business on its own.
