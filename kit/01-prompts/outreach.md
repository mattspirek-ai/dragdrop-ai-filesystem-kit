# Outreach Prompts

---

### Personalized First-Line Generator
**Use when:** Personalizing cold outreach at scale.
```
Write a genuinely personalized opening line for outreach.

INPUTS:
- About the person (role, recent post, company news): [paste]

CONSTRAINTS: Specific, not flattering-generic. One sentence. Must reference something only THIS person would recognize.
OUTPUT: 3 options.
```

---

### LinkedIn Connection + Follow-Up
**Use when:** Building a LinkedIn pipeline.
```
Write a connection request and a non-pushy follow-up.

INPUTS:
- Who they are + why I want to connect: [paste] · My offer (for context only): [paste]

OUTPUT: Connection note (≤300 chars, no pitch) · Follow-up message sent 2 days after they accept (value-first, soft ask).
```

---

### Multi-Touch Outreach Sequence
**Use when:** Running outbound.
```
Design a 5-touch, multi-channel outreach sequence.

INPUTS:
- ICP + trigger: [paste] · Offer + proof: [paste] · Channels (email/LinkedIn/etc.): [paste]

OUTPUT: For each touch — channel, timing, goal, and the message. Vary the angle each time; last touch is a graceful breakup.
```

---

### Re-Engage Cold List
**Use when:** You have an old, cold list.
```
Write a re-engagement message for a list that's gone cold.

INPUTS:
- Who they are + when/why they went cold: [paste] · What's new/better now: [paste]

OUTPUT: A short "is this still relevant?" message that's easy to reply to + a one-question survey hook.
```

---

### Event / Webinar Invite
**Use when:** Driving registrations.
```
Write outreach inviting a prospect to an event.

INPUTS:
- Event + the value of attending: [paste] · Who I'm inviting: [paste]

OUTPUT: Short personal invite (why THEM) + a forwardable version they can share with a colleague.
```
